## 🇬🇧 English Setup Instructions

### 1. Download
Click the direct download link above corresponding to your OS and CPU architecture.

### 2. CRITICAL STEP During Windows Installation! ⚠️
1. Double-click the downloaded `.exe` installer.
2. At the **bottom** of the setup window, **MUST CHECK THE BOX**:  
   ✅ **`Add python.exe to PATH`**
   > 📌 *If you skip checking this box, `install.bat` and `run.bat` will NOT be able to detect Python.*
3. Click **"Install Now"** to complete setup.

### 3. Verify Installation
Open Terminal or Command Prompt (`cmd`) and run:
```bash
python --version
```
If output shows `Python 3.12.x`, setup is complete!

## 🇹🇷 Türkçe Kurulum Adımları

### 1. İndirme
Yukarıdaki doğrudan indirme bağlantılarından İşletim Sisteminize ve İşlemci mimarinize uygun olan bağlantıya tıklayarak `.exe` veya `.pkg` dosyasını hemen indirin.

### 2. Kurulum Sırasında DİKKAT Edilmesi Gereken En Önemli Adım! ⚠️
1. İndirdiğiniz `.exe` kurulum dosyasına çift tıklayın.
2. Kurulum ekranının **en altında** yer alan kutucuğu **MUTLAKA İŞARETLEYİN**:  
   ✅ **`Add python.exe to PATH`** (Python'ı PATH'e Ekle)
   > 📌 *Bu kutucuğu işaretlemezseniz `install.bat` ve `run.bat` dosyaları Python'ı otomatik tespit edemez.*
3. **"Install Now"** butonuna basarak kurulumu bitirin.

### 3. Kurulumu Doğrulama
Komut İstemcisi'ni (`cmd`) veya Terminal'i açıp şu komutu çalıştırın:
```bash
python --version
```
`Python 3.12.x` çıktısını görüyorsanız kurulum başarıyla tamamlanmıştır!
